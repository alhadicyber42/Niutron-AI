🔄 WORKFLOW EXAMPLES:

1. Upload New Model:
   User clicks "Upload VRM"
        ↓
   File dialog opens
        ↓
   User selects .vrm file
        ↓
   Check if exists → Confirm overwrite if needed
        ↓
   Copy to assets/vrm_models/
        ↓
   Refresh dropdown list
        ↓
   Auto-select new model
        ↓
   Load to avatar
        ↓
   Save to config
        ↓
   Show success message

2. Switch Model:
   User clicks dropdown
        ↓
   Select different model
        ↓
   Load model to avatar
        ↓
   Save as active_model
        ↓
   Emit model_changed signal
        ↓
   Avatar updates instantly

3. Delete Model:
   User clicks delete button
        ↓
   Show confirmation dialog
        ↓
   User confirms
        ↓
   Delete file from disk
        ↓
   Clear from config if active
        ↓
   Refresh list
        ↓
   Show success message

4. Startup Load:
   Application starts
        ↓
   Load vrm_settings.json
        ↓
   Get active_model path
        ↓
   File exists? → Load it
        ↓
   No active? → Load first available
        ↓
   Update dropdown selection
        ↓
   Avatar ready

💻 API REFERENCE:

Functions:
  load_vrm_config() → dict
    - Load config from vrm_settings.json
    - Returns: {"active_model": str, "last_expression": str}
  
  save_vrm_config(config: dict)
    - Save config to vrm_settings.json
    - Creates directories if needed
  
  get_available_vrm_models() → list[dict]
    - Scan assets/vrm_models/ for .vrm files
    - Returns: [{"name": str, "path": str, "size": int}, ...]
    - Sorted by name

VRMAvatarPanel Methods:
  _refresh_model_list()
    - Refresh dropdown with current models
    - Restore previous selection
    - Enable/disable based on availability
  
  _on_model_selected(model_text: str)
    - Handle dropdown selection
    - Load model to avatar
    - Save to config
    - Emit model_changed signal
  
  _upload_vrm_file()
    - Open file dialog
    - Copy file to models directory
    - Handle duplicates
    - Auto-select and load
  
  _delete_current_model()
    - Get selected model
    - Confirm deletion
    - Delete file
    - Refresh list
  
  get_current_model_path() → str | None
    - Get path of currently selected model

Signals:
  model_changed(str)
    - Emitted when model changes
    - Parameter: model file path

Constants:
  VRM_MODELS_DIR: Path
    - Directory for VRM models
    - Default: assets/vrm_models/
  
  VRM_CONFIG_FILE: Path
    - Config file location
    - Default: config/vrm_settings.json

🎨 EXAMPLE CODE:

Basic Usage:
```python
# Get VRM panel
vrm_panel = ui._vrm_panel

# Get current model
model_path = vrm_panel.get_current_model_path()
print(f"Active: {model_path}")

# Refresh models
vrm_panel._refresh_model_list()

# Listen to changes
def on_model_changed(path):
    print(f"Switched to: {path}")

vrm_panel.model_changed.connect(on_model_changed)
```

Load Specific Model:
```python
from pathlib import Path

model_path = Path("assets/vrm_models/my_avatar.vrm")
if model_path.exists():
    vrm_panel.avatar.load_vrm(str(model_path))
```

Get All Models:
```python
from core.vrm_integration import get_available_vrm_models

models = get_available_vrm_models()
for model in models:
    size_mb = model['size'] / 1024 / 1024
    print(f"{model['name']}: {size_mb:.1f} MB")
```
