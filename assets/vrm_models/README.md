# Niutron VRM Models

Folder ini untuk menyimpan model VRM avatar Anda.

## Cara Menggunakan

1. **Download Model VRM**
   - Kunjungi [VRoid Hub](https://hub.vroid.com/) untuk model gratis
   - Atau gunakan [VRoid Studio](https://vroid.com/studio) untuk membuat avatar sendiri
   - Atau download dari [Booth.pm](https://booth.pm/)

2. **Letakkan File VRM**
   - Copy file `.vrm` Anda ke folder ini
   - Niutron akan otomatis mendeteksi dan memuat model pertama

3. **Format yang Didukung**
   - VRM 0.0
   - VRM 1.0
   - File harus berekstensi `.vrm`

## Model yang Direkomendasikan

Untuk performa terbaik, gunakan model dengan:
- Poly count: < 30,000 triangles
- Texture size: 2048x2048 atau lebih kecil
- Bone count: < 100 bones

## Expressions yang Didukung

Model VRM Anda harus memiliki blend shapes berikut untuk ekspresi:
- `neutral` - Ekspresi netral
- `happy` - Senang/bahagia
- `sad` - Sedih
- `angry` - Marah
- `surprised` - Kaget/terkejut
- `relaxed` - Santai/tenang
- `blink` - Kedip mata
- `aa`, `ih`, `ou`, `ee` - Bentuk mulut untuk lip sync

## Lisensi

Pastikan Anda memiliki hak untuk menggunakan model VRM yang Anda download.
Banyak model memiliki lisensi yang berbeda-beda:
- ✅ Personal Use - Untuk penggunaan pribadi
- ✅ Commercial Use - Untuk penggunaan komersial
- ❌ Redistribution - Jangan redistribusi model tanpa izin

## Troubleshooting

### Model tidak muncul
- Pastikan file berekstensi `.vrm`
- Cek apakah QtWebEngine terinstal
- Restart aplikasi Niutron

### Animasi tidak berfungsi
- Model Anda mungkin tidak memiliki blend shapes yang diperlukan
- Coba model lain dari VRoid Hub

### Performa lambat
- Gunakan model dengan poly count lebih rendah
- Kurangi ukuran texture
- Tutup aplikasi lain yang berat
